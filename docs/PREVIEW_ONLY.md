# Preview only

The [Quickstart for local and remote Jupyter](QUICKSTART.md) is the single guide for setup, connection, running the preview notebook and interpreting its PDF.

The Preview checks event identifiers in the database without exporting them. It does not build a row-level plan, open an audit journal, take remediation write locks, or apply changes. Use the [operator guide](SAFETY.md) only if separately authorized.

The other-field audit groups provenance types, demographics, death cause/type, units and coded values. It shows field-level counts, scope and all active direct candidates (including unusable ones); none are proposed for update. Death cause has no fixed domain in CDM 5.4/5.5. Unit compatibility and question–answer meaning still need review.
